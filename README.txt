YASIN RON - EXCEL FORMULA MASTER (MOBILE APP)

Files:
- index.html
- manifest.json
- service-worker.js
- icon.svg

GitHub Pages:
1. Upload all 4 files to the repository root.
2. Make sure the main file is named exactly index.html.
3. Enable Settings > Pages > Deploy from branch > main > /(root).
4. Open the GitHub Pages link on Android Chrome.
5. Chrome menu (⋮) > Add to Home screen / Install app.

This is a PWA: it opens like a mobile app, has an icon, supports standalone display,
and can cache the app for offline use after the first successful load.
