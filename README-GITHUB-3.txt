EXCEL FORMULA MASTER — YASIN RON

This is a single-file web app. Upload index.html to the root of your GitHub repository.

GitHub mobile:
1. On the Upload files page, tap "choose your files".
2. Select index.html.
3. In Commit changes, keep "Commit directly to the main branch".
4. Tap "Commit changes".

To make it live with GitHub Pages:
1. Open repository Settings.
2. Open Pages.
3. Under Build and deployment choose "Deploy from a branch".
4. Branch: main, folder: / (root).
5. Save.
6. GitHub will show the live site URL after deployment.

The app contains 200+ formulas, search, category filters, formula details, explanations, examples, sample data, copy button and full-screen mode.
